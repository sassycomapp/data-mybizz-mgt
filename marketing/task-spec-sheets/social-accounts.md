## 3. B1 — YouTube

1. On youtube.com, signed in as `mybizzlive@gmail.com`: profile icon → **Create a channel**. Name **Mybizz**, handle **@mybizzlive**.
2. YouTube Studio → **Customisation → Branding**: upload the profile picture and the YouTube banner, then **Publish**.
3. YouTube Studio → **Customisation → Basic info**: paste the long description, add the link **Mybizz** → `https://mybizz.live`, set the contact email, then **Publish**.

**Check:** youtube.com/@mybizzlive shows the disc, the banner and the description.

---

## 4. B2 — LinkedIn Company Page

1. Signed in to David's LinkedIn profile, open linkedin.com/company/setup/new and choose **Company**.
2. Name **Mybizz**; public address `mybizzlive`; website `https://mybizz.live`; industry **Software Development**; size **0–1 employees**; type **Privately held**. Upload the profile picture as the logo. Paste the short bio as the tagline. Tick the confirmation box, then **Create page**.
3. On the new page: **Edit page → Header**: upload the LinkedIn banner. **Edit page → Overview**: paste the long description, then **Save**.

**Check:** linkedin.com/company/mybizzlive shows the disc, the banner and the description.

---

## 5. B3 — Facebook Page

1. Signed in to David's Facebook profile: menu → **Pages → Create new Page**.
2. Name **Mybizz**; category **Software company**; bio: the short bio. **Create Page**.
3. Add the profile picture and the Facebook banner as the cover photo. Add the website and the contact email.
4. Page **Settings → Username**: `mybizzlive`.

**Check:** facebook.com/mybizzlive shows the disc, the cover and the short bio.

## 6. B4 — Instagram Business Account

1. Create the Instagram account `mybizzlive` with `hello@mybizz.live`. Name **Mybizz**.
2. **Settings → Account type and tools → Switch to professional account → Business**; category **Software company**.
3. **Edit profile**: profile picture, the Instagram bio, the website.
4. In the Facebook page's settings: **Linked accounts → Instagram → Connect**, and sign in as `mybizzlive`.

**Check:** instagram.com/mybizzlive shows the disc, the bio and the link; the Facebook page lists the Instagram account as linked.

## 7. B5 — TikTok Business Account

1. Sign up on tiktok.com with `hello@mybizz.live`. Username `mybizzlive`; name **Mybizz**.
2. **Settings → Account → Switch to Business Account**; category **Software & apps**.
3. **Edit profile**: profile picture, the short bio, and the website in the **Website** field when TikTok offers it.

**Check:** tiktok.com/@mybizzlive shows the disc and the short bio.

2. Record each account on the **Accounts** sheet of `marketing-project-plan.xlsx`: address, sign-in email, 2-step verification and date created. Passwords are never written there.
