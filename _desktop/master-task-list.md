6. Research https://github.com/albertlauncher/albert
https://albertlauncher.github.io/
Albert Launcher is a fast, plugin-based keyboard launcher for desktop systems, providing unified and efficient access to your machine, technically implemented as a keyboard launcher written in C++/Qt. Its plugin-based architecture makes it extremely flexible and powerful, letting plugins serve as either frontends or functional extensions, with support for building extensions via embedded Python modules or a CGI-style approach in any language. Performance and efficiency are core design goals — it's built to keep up with rapid muscle-memory typing — while its flexibility lets it function as anything from a simple app launcher to a full system command palette, and it ships with a curated, peer-reviewed collection of actively maintained plugins so it works well out of the box without hunting for extensions.

8. Notesnook
https://github.com/streetwriters/notesnook
The main reason I stuck with OneNote for so long was the way it organizes notes. Most newer apps force you to use complex databases (looking at you, Notion), objects, or linked mind maps that take too much effort to manage. Notesnook keeps things simple. It uses the exact same setup I was already used to: Notebooks, topics, and sub-topics. Moving my work over was seamless because I didn’t have to rethink my entire filing system.
